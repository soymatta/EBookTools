# EBookTools

Set of tools for your EBooks and EReaders. Available as Python CLI and Web app (Vercel).

## Tools

- **Compress Books** - Reduce PDF and EPUB file sizes without losing quality
- **EBook to Voice** - Convert ebooks to audio using offline text-to-speech
- **EPUB ↔ PDF** - Convert between EPUB and PDF formats
- **Metadata Editor** - Edit title, author, cover and other book metadata
- **AutoName** - Rename badly named books using metadata from free APIs
